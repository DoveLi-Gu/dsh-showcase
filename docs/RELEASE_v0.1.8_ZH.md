# DSH Showcase v0.1.8

2026-10-17 · 双主题界面更新与鲸鱼娘任务互动

## 本次更新

- **鲸鱼娘融入任务内容**：Q 版角色、任务说明、状态和统计放在同一条蓝色内容带里；完成时抬头、待复核时专注、失败时伏下，表情以真实报告结果为准。
- **轻量互动与无障碍**：鼠标靠近任务或统计时，角色轻微转向并回应；点击角色可打开相关验证回执或本地产物，支持键盘和触屏。“动态回应”默认尊重系统减少动效偏好，关闭后仍显示状态表情。
- **终末地工业界面完善**：保留深色等高线首屏、大标题与信号色，整理导航、验证回执、设置面板和移动端排版；修复加载黄条结束后的重复揭示。
- **预览与正式导出一致**：两套主题默认都使用插件海报渲染器，修复正式导出将内置角色当作自定义立绘而阻止表情切换的问题。真正的自定义立绘仍保持不变。
- **演示状态不再误导**：预览明确显示“演示状态：待复核”；正式报告继续展示真实任务结果，不会套用演示文案。
- **截图与许可同步**：README 更新双主题桌面、手机首屏和完整长图；当前预览使用带版本、尺寸与时间记录的实拍截图。Q 版素材及离线内嵌版本补齐来源和上游许可。
- **安全修复**：构建工具间接依赖 `source-map-js` 更新至 `1.2.2`，修复 [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)。

## 升级方式

在原先安装插件的 DSH 环境执行：

```sh
dsh plugin --profile web add dsh-showcase@0.1.8
```

使用其他 profile 时，将 `web` 替换成你的实际 profile。重新加载插件后，对目标项目重新运行 `showcase_layout_summary`。旧 HTML 是静态快照，不会自动更新；新生成的 `.showcase/layout-poster.html` 才会使用新版界面。

## 兼容范围与限制

- Node.js `22.19+` 或 `24+`；DSH `>=0.2.0-rc.2 <0.3.0`。本次不修改报告格式或目标项目配置。
- 插件整理目标项目自己的证据，不会将仓库中的演示截图、Diff 或测试结果带入正式报告。
- 截图仍需自行采集；缺少有效证据、未配置测试、无 Git 或失败回执时，状态会按实际情况显示。
- 动态回应依赖 JavaScript；关闭脚本或动效后仍保留静态角色、真实状态和报告内容。角色素材和互动脚本随 HTML 内嵌，不需要联网加载。
- 构建仍有一个约 504 kB 的预览分块体积提示，不影响构建通过；实际发布包不包含 Vite 的 `dist/`。
