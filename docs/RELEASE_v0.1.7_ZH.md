# DSH Showcase v0.1.7

2026-10-16 · 鲸鱼娘主题同步到实际插件海报

## 本次更新

0.1.6 的鲸鱼娘改动此前只作用于源码演示页。这次将相同的细网格、潮汐环与角色清晰度规则同步到 npm 插件生成的自包含 HTML，不再只在开发预览中生效。

- **共用视觉样式**：演示页和插件读取同一个鱼主题视觉模块，该模块随 npm 包一起发布。
- **完整展示角色**：插件保留独立立绘栏与完整人物，采用小幅位移动效；手机端减少顶部空白，平板端避免立绘与后续内容相撞。
- **验证回执更易读**：命令、状态和输出入口分行排列，长命令支持换行；修复对比区标题、隐私提示和失败状态的文字对比度。
- **保持证据真实**：无 Git、无测试、无截图及失败状态仍按报告展示，不使用演示页的固定完成文案。

## 检查范围

- 类型检查、149 项自动化测试、生产构建和 npm 文件清单检查。
- 通过插件生成独立 HTML，检查 1000×900、1500×1000、2000×1200、768×1024、390×844 和 320×740 视口。
- 覆盖长项目名、长命令、输出展开、英文失败回执，以及无 Git / 无测试 / 无截图的非视觉项目。
- 从实际 npm tarball 安装后再次调用海报生成器，验证共享样式和内嵌角色素材随包可用。

验收使用明确标注的测试样例，不代表某个用户项目已通过验证。

## 升级后怎么生效

在安装插件的 DSH 环境中更新到 `dsh-showcase@0.1.7`，重新加载插件，选择“蓝色大肥鱼”主题，然后对目标项目重新运行 `showcase_layout_summary`。

旧 HTML 是静态快照，不会自动换肤。新生成的 `.showcase/layout-poster.html` 才会采用新版样式。安装与配置见 [README](../README.md#快速开始)。

本次不更改终末地主题、DSH 兼容范围、报告格式或安装方式。角色素材说明见 [CHARACTER_ASSET_NOTICE.md](../CHARACTER_ASSET_NOTICE.md)。
