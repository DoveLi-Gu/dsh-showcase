# DSH Showcase v0.1.6

2026-10-16 · 主题视觉更新与素材清理

## 本次更新

- **终末地帝江号**：报告首屏采用更鲜明的深色工业工作台，强化等高线、标题、编号水印、黄色结构带和切角交付中继。
- **蓝色大肥鱼演示页**：增加细网格与潮汐环，调整鲸鱼娘的对比度、透明度及手机端位置；移动端交付贴纸不再拉满整行。
- **素材清理**：删除未使用的工业建筑照片，更新素材说明。

## 升级方式

在安装插件的 DSH 环境中更新到 `dsh-showcase@0.1.6`，完成后按原有方式重新加载插件。安装步骤见 [README](../README.md#快速开始)。

使用源码演示的用户，更新仓库后执行：

```powershell
npm ci
npm run dev
```

已导出的 HTML 是静态快照，需要重新生成报告才能获得新版终末地样式。

## 更新范围

终末地报告样式随 npm 插件发布。蓝色大肥鱼本次改动属于 GitHub 源码演示页，未更改 npm 自包含鱼主题海报的既有布局。DSH 兼容范围、报告格式及插件配置方式保持不变。

角色与主题演示素材的使用说明见 [CHARACTER_ASSET_NOTICE.md](../CHARACTER_ASSET_NOTICE.md)。
